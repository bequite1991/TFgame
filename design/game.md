# 游戏主界面 — `/game` （game.md）

> 核心页面。移动端竖屏优先：顶部 HUD 条 → Canvas 游戏区（62vh）→ 底部建塔面板。桌面：中央画布 + 左右侧栏。

## 布局结构

```
┌─────────────────────────┐
│ TopHUD: ♥生命 💰金币 波次 ⏸ ⏩ │  高 56px, --bg-glass
├─────────────────────────┤
│                         │
│   GameCanvas 540×960    │  逻辑分辨率, CSS 等比
│   (map-bg + 塔 + 敌人)  │
│                         │
├─────────────────────────┤
│ BuildPanel (抽屉式)      │  高 ~38vh, 可收起
│ 塔卡片×4 横向滑动        │
└─────────────────────────┘
```

### T1 TopHUD
- 左：`/icon-heart.svg` + 生命条（宽 80px，渐变 `--hp`→`--gold`）+ 数字 `20/20`（Orbitron 14px）。
- 中：`/icon-coin.svg` + 金币数（`--gold`, 18px 700，增加时 +N 浮字从图标飘出 600ms）；`/icon-wave.svg` + `第 3/15 波`。
- 右：暂停 `/icon-pause.svg`、2倍速 `/icon-speed.svg`（激活态青色填充）、设置 `/icon-gear.svg`（弹出音量/画质/退出）。
- **Animation**：生命减少时 HUD 红闪 300ms + 全屏 vignette 红边脉冲；波次变化时数字放大 1.2→1 回弹。

### T2 GameCanvas
- 层序（Canvas 内绘制顺序）：`map-bg.png` → 路径（发光青色虚线流动动画，dashOffset 随时间推进）→ 可建格提示（选中建塔模式时，合法格青色脉冲高亮）→ 基地（`map-base.png` + 护罩弧光呼吸）→ 塔（含射程预览圈）→ 敌人（HP 条头顶，宽 40px 高 4px）→ 弹道/激光/粒子特效 → 浮字。
- **选中塔**：点击已建塔 → 底部切换为塔详情面板（见 T3b），画布上画射程圈（青色实线+内部 8% 填充）。
- **波次预告**：下一波开始前，顶部 HUD 下缘滑出一条 48px 预告条：敌人小图标 ×N 列表 + 3s 倒计时数字，BOSS 波品红底 + "⚠ BOSS 来袭" 闪烁。
- **Animation（Canvas 内）**：激光束 100ms 亮线衰减；导弹为弧线弹道（二次贝塞尔）+ 命中爆炸粒子 16 个；减速塔为 1 格半径冰蓝脉冲环扩散 300ms；电磁炮蓄能 1.2s 炮口聚光后发射 6px 紫色贯穿光束；敌人受击闪白 80ms；死亡缩小 0.9→0 + 碎裂粒子 + `+金币` 金色浮字上升 40px 渐隐。BOSS 出场屏幕震动 6px 衰减 500ms + 品红边脉冲。

### T3a BuildPanel（建塔模式）
- 4 张塔卡片横滑（移动端 scroll-snap），每卡 96px 宽：塔素材图（64px）、名称、费用（金币图标+数字）、微型特性标签（"贯穿"/"溅射"/"减速"/"直线"）。
- 选中卡片 → 进入"放置模式"：面板收起为提示条"点击地图格子放置 · 点击空白处取消"，画布显示合法格。
- 金币不足时卡片灰化 + 费用数字转 `--hp` 红色。
- **Animation**：面板从底部 `y:100%→0, spring(damping 26)`；卡片选中 `scale 1.05` + 青色描边发光。

### T3b TowerDetailPanel（塔详情/升级模式）
- 内容：塔大图（96px）、名称+等级徽标（Lv1/2/3 六边形）、属性行（伤害/射程/射速，当前值→升级后值用绿色箭头）、累计击杀数、按钮行：**升级**（费用，满级置灰显示 MAX）、**出售**（+返还金额，危险按钮）。
- **Animation**：属性差值数字 `count-up` 400ms；升级成功时面板中央光环扩散 + "LEVEL UP" 字符动画。

### T4 结算覆盖层（胜利/失败）
- 全屏 `--bg-glass` 模糊遮罩，中央 PanelCard：
  - 顶部插画 `/victory-art.png` 或 `/defeat-art.png`（3:2，圆角切角）。
  - 标题："防线守住了！" / "殖民地陷落…"（Orbitron 32px，胜青色 / 负品红）。
  - 战绩表：波次、击杀数、漏怪数、剩余生命、金币赚取、用时（6 行键值对）。
  - 成就解锁提示（若新成就：横向滑入金色卡片 + `/icon-trophy.svg` 旋转入场）。
  - 按钮：再来一局（主）/ 返回主页（幽灵）。
- **Animation**：卡片 `scale 0.8→1 + opacity, spring`；战绩行 stagger 0.08s 上滑；胜利时金色粒子从顶部飘落 3s。

## 侧栏（仅桌面 ≥1024px）
- **左栏**：图鉴速查 —— 当前波敌人属性小卡 + 克制提示（如"甲壳兽：装甲抗激光，建议导弹/电磁炮"）。
- **右栏**：波次列表（15 行，当前波高亮，已过波打勾，BOSS 波品红图标）。

## 交互清单
| 操作 | 触屏 | 鼠标 |
|---|---|---|
| 建塔 | 点卡片→点格子 | 同左 |
| 选中塔 | 点击塔 | 点击塔（悬停显示射程） |
| 取消 | 点空白/返回键 | 右键/Esc |
| 暂停/加速 | HUD 按钮 | 同 + 空格/2 快捷键 |
