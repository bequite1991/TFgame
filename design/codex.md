# 图鉴页 — `/codex` （codex.md）

> 氛围：全息博物馆/数据库终端。玩家查阅防御塔与敌人的完整档案。

## 布局

### C1 页头横幅
- 背景 `/codex-banner.png`（高 200px 移动端 / 320px 桌面，cover，底部渐隐入 `--bg-deep`）。
- 标题 "TACTICAL DATABASE / 战术图鉴"（Orbitron 700 28px + 中文副标）。
- **Animation**：标题字符级 `y:20→0, stagger 0.03s`；横幅背景缓慢 `scale 1→1.06, 8s alternate`。

### C2 分类 Tab（粘性吸顶）
- Tab：**防御系统 / 虫群档案**（下划线滑动指示器，青色 2px）。
- Tab 下方次级筛选（虫群档案时显示）：全部 / 普通 / 快速 / 坦克 / 特殊 / BOSS（胶囊 chips，可多选）。
- **Animation**：Tab 切换内容 `opacity 0→1 + y 12→0, 250ms`；指示器 layoutId 滑动。

### C3 防御系统 Tab 内容
- 4 张大卡片纵向排列（桌面 2×2 网格，gap 24px）。每卡：
  - 左侧塔素材大图（180px，悬浮微旋转 `rotate ±2deg, 4s alternate`）。
  - 右侧：名称（中英）、定位一句话（如"激光塔——精准点杀的哨戒之瞳"）、特性标签。
  - **三级数值表**：小表格 3 行（Lv1/Lv2/Lv3）× 4 列（伤害/射程/射速/费用），当前 hover 行高亮青色。
  - 克制说明条："擅长：爬行者/迅捷兽 · 乏力：甲壳兽"。
- **Animation**：卡片入视口 stagger 0.1s `y:40→0`；表格行 hover `background` 0→`rgba(34,224,255,0.06)` 150ms。

### C4 虫群档案 Tab 内容
- 6 张敌人卡片（移动端单列，桌面 3 列网格）。每卡：
  - 顶部敌人素材（220px 高区，暗紫径向渐变底，素材带绿色 glow 投影）。
  - 名称 + 威胁等级徽章（★1-5，BOSS 为品红 "APEX" 徽章）。
  - 属性条可视化：HP/速度/威胁 三条横条（宽度按归一化值，渐变填充）。
  - 数值小字：HP / 速度 / 击杀奖励 / 漏怪伤害。
  - 特性描述 1-2 行（含机制说明，如"死亡分裂为两只爬行者"）。
  - 克制提示："弱点：溅射伤害"。
- BOSS 卡片跨整行，素材更大（300px），品红描边，附带狂暴机制说明。
- **Animation**：卡片 hover（桌面）`translateY -6px + box-shadow glow`；属性条入视口时宽度 0→目标 800ms easeOut。
